# Plan 2 — Gameplan UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Gameplan desktop UI: every screen in `docs/ui/screens.md`, served by the engine at `http://127.0.0.1:4747/`, live-synced with agent writes, ready to be wrapped by the Tauri shell in Plan 3.

**Architecture:** A Vite + React SPA in `ui/`, built to `dist/ui/` and served by the existing Hono app (SPA fallback). It talks only to the existing `/api/*` JSON and `/events` SSE: no new engine logic except static serving and a host/origin guard. Server state lives in TanStack Query; every SSE `change` invalidates queries, highlights agent-touched rows and feeds a session undo stack. The timeline is hand-built DOM + SVG driven by pure geometry functions.

**Tech Stack:** React 19.3 · Vite 8.4 · @vitejs/plugin-react 6.3 · @tanstack/react-query 5.108 · wouter 3.13 (routing) · @fontsource-variable/inter 5.3 · plain CSS with custom properties (no UI kit, no Tailwind) · Vitest 5 + jsdom 31 + @testing-library/react 16.3 · @playwright/test 1.65 (one smoke suite).

**Spec:** `docs/ui/` — `screens.md` (what each screen holds), `ui-rules.md`, `content-rules.md`, `ui-tokens.md`, `design-language.md`. Read all five before Task 1. Engine read models: `src/domain/queries.ts`; routes: `src/server/app.ts`.

## Global Constraints

- Use only values from `docs/ui/ui-tokens.md`, exposed as CSS variables `--gp-<token>`. A raw hex, px size or duration in a component's CSS that isn't a token is a review failure. Exceptions: `0`, `1px` lines, `50%`, `100%`.
- Font: Inter variable, bundled via `@fontsource-variable/inter` (no network fonts). Weights 400/500/600 only. Type sizes only from the scale (22, 19, 17, 13, 12.5, 12, 11.5, 11).
- Copy follows `docs/ui/content-rules.md`. No subtitles or helper text under headings. Sentence case. Buttons ≤ 3 words. No exclamation marks, no emoji in chrome.
- Words: "to-do" (never microtask/subtask), "area", "executor" shown as `Me · AI · Together` (engine values `manual · ai · together`), "Needs review", "Where I left off", "Inbox".
- Actor labels: `you` → "You"; `ai:<client>` → the client name as the engine stores it (e.g. "Claude Code", "Codex"). Never "AI" when a name is known.
- Dates only, no times. Formats: `Nov 27` · `Friday, 27 November` · `Nov 28 → Dec 3` · year shown only when not the current year.
- One primary (accent-filled) button per view at most.
- UI writes never cascade reschedules (`cascade: false`). The UI is the only place dates are dragged.
- Light and dark are both first-class; appearance `system | light | dark` and `accent` come from `GET /api/settings`.
- `prefers-reduced-motion`, `prefers-reduced-transparency`, `prefers-contrast` honoured as in `ui-rules.md` › Accessibility.
- Every icon-only control has `aria-label`; titles render with `dir="auto"`.
- Min window 1080×680; designed at 1440×900. No horizontal page scroll at 1080.
- No new runtime dependencies beyond the Tech Stack list. Icons are inline SVG components (24-grid, stroke 1.8, round caps), not an icon package.
- Engine tests (`test/**/*.test.ts`) keep passing unchanged.
- No global keyboard shortcut (system-wide). In-app shortcuts only.

## Review Focus

1. **An agent writes while you are editing a field** (SSE invalidation refetches the task). Expected: your in-progress text and caret stay; the refetch doesn't clobber a focused input; the row highlight still shows. → test in Task 3 (`useDraft`) and Task 9.
2. **A request from another website or a DNS-rebound host hits `127.0.0.1:4747/api`.** Expected: 403 for a foreign `Host`, and for a write with a foreign `Origin`; `/mcp` keeps working through a tunnel (token-protected). → tests in Task 1.
3. **The engine restarts or the laptop sleeps** (SSE drops). Expected: EventSource reconnects, on `ready` all queries refetch, and a quiet "Gameplan engine isn't running" + "Restart" bar shows only while `/api/home` fails. → test in Task 3.
4. **Revert conflict or a refused write** (`409 conflict`, `403 forbidden`, `400 invalid`). Expected: one-line message in place from content-rules ("Changed since — reload to see the latest", "Would create a loop"), no crash, optimistic state rolled back. → tests in Task 3 (error mapping) and Task 6 (drag rollback).
5. **Mixed Hebrew/English and very long titles** in rows, bars, pane, palette. Expected: `dir="auto"`, single-line ellipsis in rows and bars, full title in pane and on hover (`title` attribute), bar labels never overflow the bar. → tests in Task 5 and Task 7.
